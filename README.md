# Django_messageing

## Realtime Chat App (Django Channels)

This project is a real-time messaging application built with Django Channels.
It allows multiple users to log in and exchange messages instantly using WebSockets.

## Features
- User login and logout
- Real-time group chat using WebSockets
- Multiple users chatting at the same time

## Technologies Used
Python, Django, Django Channels, Daphne, HTML, JavaScript

## How to Run
1. git clone [your repo link]
2. cd [repo folder name]
3. python -m venv venv
4. venv\Scripts\activate
5. pip install -r requirements.txt
6. python manage.py migrate
7. python manage.py createsuperuser  (run twice for two users)
8. python manage.py runserver
9. Open http://127.0.0.1:8000/ in two different browsers
